# Beast Craft pixel style

Goal: a warm, readable, all-ages "travel journal" pixel look (content bible: wonder first, danger
second, never grim) that can be authored as text and built by code.

## Palette (`palette.json`)
31 colours + transparent, one character each. Use nothing else.

| Group | Chars (dark -> light) | Use |
| --- | --- | --- |
| Outline | `K` | the only outline colour (deep plum-black, not pure black) |
| Neutrals | `1 2 3 4` | stone, hide, metal, UI; `4` is warm cream, not white |
| Fire | `r o y Y` | Phoenix, embers, the red potion |
| Water / Ice | `b c C` (+ `4`) | water, ice, crystal, *rare rarity* blue |
| Earth | `n m M` (+ `H`) | soil, sandstone, wood, leather, canvas shade |
| Nature | `g G l` | moss, grass, leaves, thorns |
| Air | `A a` (+ `4`) | wind, clouds, glass |
| Metal | `1 2 3` + `q` (copper) | iron, copper |
| Light | `H 4 w`, `h y` gold | Kirin, halos, gold trim |
| Dark / Gloam | `p P u` | the Gloam haze, Dark element, gloamed eyes |
| Skin | `S s` | avatar (unused in this test) |
| Glow | `Z` | halos, sparkles, embers: the only colour with **no outline** |
| Misc | `e` | charred cracks |

Element colour must be obvious at 1x: every beast's dominant mass is its element ramp
(Phoenix = Fire ramp, Golem = Earth ramp + Nature moss, Kirin = cream/gold Light ramp).
Gloamed enemies always carry the Gloam purple (`p P u`) somewhere (mane, haze wisps, eyes),
whatever their element.

## Rules
1. **Outline:** 1 px `K`, outside the silhouette, 4-neighbour (rounded corners). Generated by
   `build.py` (`outline: auto`); only draw `K` by hand for *interior* lines (brows, a head in
   front of a body, a hood opening). Glows (`nooutline: Z` etc.) never cast an outline.
   Tiles have no outline.
2. **Light:** from the top-left, always. `autoshade: yes` rims the *mid* colour of each ramp
   (light on top/left edges, dark on bottom/right edges). Hand-placed darks and lights always
   win over autoshade, so form shading (chest glow, belly shadow, seams) is drawn by hand.
3. **Ramps:** 2-3 shades per material, from `ramps` in the palette. No anti-aliasing to the
   background; no gradients longer than 3 steps.
4. **Dithering:** only for haze (Gloam) and sparse texture on tiles; never on characters' skin.
5. **Sizes:** beasts/enemies 32x32 (content within 30x30 so the outline fits), items and map
   markers 16x16, map tiles 16x16 seamless, battle hex tiles 32x36 (pointy-top), particles 5x5,
   effect flipbooks 24x24-32x32 per frame. One pixel grid: never scale a sprite by a non-integer.
   Effects meant to be tinted per element in game are drawn in the white/cream ramp (`w 4 3 2`).
6. **Shapes:** big simple silhouette first (it must read at 1x as a black blob), then 1-2 focal
   details (eyes, chest glow, clasp). Front or three-quarter idle pose facing viewer-left.
7. **Rarity on items:** common = natural materials (bone, twine, leaf); rare = blue `c` body with
   gold `y` trim. (Epic/legendary not yet defined.)
8. **Map markers** must contrast with every ground tile: light canvas `4/H` + dark door/outline.

## Sprite file format
See the docstring at the top of `build.py`. Header keys: `name, label, kind, size, outline,
autoshade, noshade, nooutline, frame_ms, artkey`; frames separated by `---`. Generated kinds
(`fx` with `generator: burst`, `hex`) add `generator, frames, ramp, seed` / `texture, fill, edge`.
