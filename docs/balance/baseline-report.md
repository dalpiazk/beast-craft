# Beast Craft balance simulator report

Generated by `Tooling/BalanceSim` (local-only tooling, not a CI job). These numbers are inputs to design
decisions; nothing here is applied to the roster automatically. The run is deterministic: the same roster,
code and arguments produce a byte-identical report.

## Configuration

- Roster: `BeastCraft/Assets/_Project/Data/Creatures/beast-roster.json` (10 species)
- Levels: 1, 25, 50, 100; no gear; no avatar
- Modes: `elemental`, `neutral`
- Arena: Medium, 1v1, mirrored central start tiles in each deployment zone
- Round-robin: every pair of distinct species, played twice per level and mode with sides swapped (18 games per beast per level per mode; mirror matches skipped); 720 battles total
- Max rounds: 200 (a battle reaching it is a stalemate); base seed: 12345
- Standard kit, in fire-priority order:
  - Blast: Special, power 40, range 3, cooldown 2
  - Strike: Physical, power 40, range 1, cooldown 1
  - Single target, nearest enemy. `elemental` mode: both skills carry the beast's first element. `neutral`
    mode: both are `None`, isolating stat distribution from the element chart.
- Win rate = wins / games; mutual defeats and stalemates count as games but not wins. Flags: win rate above 60.0% or below 40.0%, a swing of more than 25.0 points across levels, and any stalemate.
