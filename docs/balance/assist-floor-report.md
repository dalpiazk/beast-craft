# Beast Craft adaptive-assist floor

Generated by `dotnet run --project Tooling/BalanceSim -c Release -- --mode assistfloor`
(see Tooling/BalanceSim/README.md, "Adaptive assist floor"). Per shape, the multiplier (as a scale on the shipping table) at
which the WEAK owned-roster pick (`--mode typical`'s population) reaches 70.0% (a region boss 60.0%), at every level in
`--levels 10,30,50,70,90` and every region's own boss; the shipped scale is the minimum (strongest discount) needed, so the
target is met everywhere, not just at the level it binds. Also the expected attempts to clear at equal level, assist on
(assumed step 0.10 = -10% a loss): the producer's bar is <= 3 for an ordinary fight, <= 5 for a boss.
