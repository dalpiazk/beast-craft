# Beast Craft skill-progression pacing report

Generated by `dotnet run --project Tooling/BalanceSim -c Release -- --mode pacing` (see Tooling/BalanceSim/README.md, "Pacing").
A Monte Carlo campaign model, not fought battles: practice XP and drops go through the real `SkillProgression` and
`LootRoller` against `drop-tables.json`. Tunable starting values, not confirmed balance.

## Configuration

- Campaigns: 1000 (1000 per base seed; base seed 12345), 500 battles each
- Encounter level: 1 + battle / 5 (level 100 from battle 496)
- Shape mix: `solo` 15, `elite` 20, `squad` 35, `horde` 30; clear chance 80.0% (drops on clears only; practice either way)
- Focus skill fires 3-9 times per battle (uniform) at 10 XP per use; the secondary skill the same
- Materials: `essence_shard` tier 1 = 250 XP, `essence_crystal` tier 2 = 1000 XP, `essence_core` tier 3 = 4000 XP
- Policy: pass a waiting gate with the lowest adequate material; feed lowest tier first while below the cap, keeping one
  material per tier a later gate needs; spill the rest to the secondary skill.
